# Kerf

[sceeps.github.io/kerf](https://sceeps.github.io/kerf/) · учебная работа,
магазин придуман

Магазин кованых ножей малыми партиями. Гьюто №1: сталь 52100, твёрдость 61 HRC,
обух 2,1 мм, вес 187 г.

Карточка сделана как протокол измерений с метрологического поста: гранитная
плита, штангенциркуль, холодная сталь. Без тёплого дерева и медных бликов,
которыми обычно продают ручную работу — нож тут не воспевают, а измеряют.

Один из шести разделов протокола называется «в чём нож плох», и стоит он там же,
где характеристики. На дорогой покупке честно названный недостаток убеждает
лучше, чем ещё один абзац про страсть к ремеслу.

Шрифты: Big Shoulders Display и Chivo. `base` — `/kerf/`.

```bash
npm install
npm run dev
npm run build
```
