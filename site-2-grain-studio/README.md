# Grain

[sceeps.github.io/grain](https://sceeps.github.io/grain/) · учебная работа,
студия придумана

Сайт студии бренда и моушна: айдентика, анимация, цифровые продукты.

Крупный текст набран с намеренным браком печати. В офсете формы иногда встают
неточно, краски расходятся, и у буквы появляется цветной двойник — здесь так
сделаны все заголовки: лайм и магента разъезжаются на чёрном. Буквы лежат в два
слоя с разным сдвигом, сверху плёночное зерно.

Бегущие строки останавливаются, если в системе выключены анимации: постоянно
ползущий текст тяжело переносится, и это не мелочь, а требование доступности.

Шрифты: Unbounded и Work Sans. `base` — `/grain/`.

```bash
npm install
npm run dev
npm run build
```
