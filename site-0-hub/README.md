# Визитка

Корень сайта: [sceeps.github.io](https://sceeps.github.io/). Ведёт на остальные
пять.

Вид — лицевая панель прибора: крашеная сталь, эмалированные таблички на винтах,
утопленные поля. Цвет каждого из пяти проектов появляется тут только узкой
светящейся полоской над его скриншотом. Иначе пять пёстрых палитр рядом
начинают спорить друг с другом, и получается каша.

Шрифты: Tektur, Geologica, PT Mono — все три с нормальной кириллицей, что для
акцидентных гарнитур редкость.

Скриншоты в `public/shots/` сняты с этих же пяти сайтов, по два на каждый:
широкий и телефонный. Переключаются через `<picture>`, чтобы на телефон не
уезжал файл шириной 2880 пикселей.

`base` тут `/` — визитка лежит в корне домена.

```bash
npm install
npm run dev
npm run build
npm run lint
```
