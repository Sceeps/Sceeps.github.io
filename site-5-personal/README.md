# Mara Solden

[sceeps.github.io/mara](https://sceeps.github.io/mara/) · учебная работа,
персонаж вымышленный

Личный сайт инженера. Четыре проекта, и у каждого написано: что мешало, что
сделали, какая цифра сдвинулась и чем за это заплатили.

Вид — комплект чертежей после проверки: синяя печать листа и правки красным
карандашом поверх, угловой штамп, список ревизий. Правки нарочно оставлены на
виду: у каждого проекта есть раздел «сначала сделал неправильно».

Опыт описан не через «отвечал за» и «участвовал в», а как лист с размерами и
допусками, где у каждой цифры есть источник.

Шрифты: Overpass и Andada Pro. `base` — `/mara/`.

```bash
npm install
npm run dev
npm run build
```
