# Пять сайтов и визитка

**→ [sceeps.github.io](https://sceeps.github.io/)**

Визитка в корне и пять сайтов под ней. Всё рабочее, всё собирается отсюда.

## Сразу честно

Это учебные работы. Названия фирм, люди, цены и цифры внутри придуманы:
заказчиков не было, пользователей тоже. Настоящие тут только дизайн и код.

## Что за сайты

Затея была такая: не пять вариантов одного шаблона, а пять разных решений. У
каждого свои шрифты, своя палитра и своя реальная вещь, из которой взят вид —
мне не хотелось лепить пять мудбордов из чужих сайтов.

| Сайт | Что это | Откуда такой вид |
|---|---|---|
| [Ledger](https://sceeps.github.io/ledger/) | Лендинг сервиса для финансовых отделов | Зелёная полосатая бумага, на которой печатали бухгалтерские книги, и пометки красной ручкой поверх. В середине — журнал проводок, который заполняется сам |
| [Grain](https://sceeps.github.io/grain/) | Сайт студии бренда и моушна | Брак офсетной печати, сделанный намеренно: краски разъезжаются, и у крупных букв появляется цветной двойник — лайм и магента на чёрном |
| [Datum](https://sceeps.github.io/datum/) | Дашборд аналитики | Все цифры — один сюжет: релиз, шторм повторных запросов, упавшая нода, хотфикс. Поэтому графики согласуются друг с другом, а не показывают случайный шум |
| [Kerf](https://sceeps.github.io/kerf/) | Магазин кованых ножей | Протокол измерений с метрологического поста: гранитная плита, штангенциркуль, холодная сталь. Один из разделов — «в чём нож плох» |
| [Mara Solden](https://sceeps.github.io/mara/) | Личный сайт, персонаж вымышленный | Комплект чертежей после проверки: синяя печать, красный карандаш правок, угловой штамп, список ревизий |

Визитка — шестой дизайн, лицевая панель прибора. Цвет каждого проекта появляется
на ней только узкой светящейся полоской над скриншотом: пять пёстрых палитр
рядом иначе спорят друг с другом.

## На чём сделано

React 19, Vite, Tailwind v4, Motion. У Datum ещё Recharts. Линтер — oxlint.

Tailwind v4 тут CSS-first: токены лежат в `@theme` внутри CSS, файла
`tailwind.config.js` нет вообще. Цвета в OKLCH. Контраст я не прикидывал на
глаз, а считал: OKLCH → linear sRGB → относительная яркость → WCAG.

## Устройство

```
site-0-hub/             визитка,  base '/'
site-1-ledger-saas/     Ledger,   base '/ledger/'
site-2-grain-studio/    Grain,    base '/grain/'
site-3-datum-dashboard/ Datum,    base '/datum/'
site-4-kerf-store/      Kerf,     base '/kerf/'
site-5-personal/        Mara,     base '/mara/'
```

Шесть отдельных проектов. Каждому дочернему выставлен свой `base` — без этого
на подпути отвалятся все скрипты и стили, и вместо сайта будет белый экран.
Грабли известные, поэтому сборка это проверяет: если `index.html` не ссылается
на ассеты своей папки, она падает, а не публикует пустую страницу.

`dist/` и `node_modules/` не в репозитории — их собирает GitHub Actions.

## Запустить у себя

```bash
npm install --prefix site-0-hub
npm run dev --prefix site-0-hub
```

Вместо `site-0-hub` — любой из остальных. Ещё есть `build` и `lint`.
