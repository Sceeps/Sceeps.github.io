# Ledger

[sceeps.github.io/ledger](https://sceeps.github.io/ledger/) · учебная работа,
фирма придумана

Лендинг сервиса для финансовых отделов: корпоративные карты и закрытие месяца.
Карта проверяет лимит и политику прямо при оплате, а не через две недели в
отчёте.

Вид взят с зелёной полосатой бумаги — на такой печатали бухгалтерские книги,
пока этим занимались принтеры с непрерывной подачей. Поверх идут пометки красной
ручкой, как в отчёте после проверки.

Главное на странице — журнал проводок, который заполняется сам. Каждая операция
пишет две строки, дебет и кредит, и внизу сходится баланс. Суммы считаются в
копейках, а не в дробных рублях, иначе на длинном списке накапливается ошибка
округления.

Шрифты: Anek Latin и Martian Mono. `base` — `/ledger/`.

```bash
npm install
npm run dev
npm run build
```
