# Datum

[sceeps.github.io/datum](https://sceeps.github.io/datum/) · учебная работа,
данные синтетические

Дашборд аналитики: поток событий, разбор аномалий, сырой лог. Это сам рабочий
экран, а не лендинг про него — поэтому тут нет ни героя, ни кнопки «попробовать
бесплатно».

Придумана не картинка, а история. Все цифры на экране — один сюжет: вышел релиз,
клиенты начали повторять запросы, нода не выдержала, прилетел хотфикс. Поэтому
графики согласуются друг с другом: провал приёма событий совпадает по времени с
записью в логе и с всплеском аномалий. Случайные числа так себя не ведут, и
именно по этому обычно видно поддельный дашборд.

Экран собран вокруг вопросов, которые задают по порядку: можно ли доверять
данным, что сломалось, насколько, когда, чего это стоило, покажи события.

Графики на Recharts. Шрифты: Golos Text и Spline Sans Mono. `base` — `/datum/`.

```bash
npm install
npm run dev
npm run build
```
